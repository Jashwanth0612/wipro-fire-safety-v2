# Wipro V2 working agreement

For every task on this project:
1. Read `docs/PROJECT_CHECKLIST.md` and inspect current code/deployment before deciding what remains.
2. Work on unfinished, authorized tasks. Verify completed claims; do not mark an item done solely because a screen exists.
3. Update checklist evidence, date, commit/release and exact blockers after changes.
4. Preserve V1, company branding and original catalogue details. Never invent inventory quantities, client claims, certifications or testimonials.
5. Stock changes must use the atomic stock-movement RPC. Never restore direct stock overwrites or edit/delete history to fix an error.
6. Keep secrets out of Git and frontend code. Customer enquiries, internal notes and stock history are staff-only.
7. Run relevant API/frontend tests and production build before releasing code. Database changes need transaction/access-control tests.
8. Real owner data, a separate father's account, paid services, customer messaging and recovery credentials need their specific inputs/authorization; broad project access is not evidence of those facts.
